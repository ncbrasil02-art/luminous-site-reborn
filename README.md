# NovaTech Brilliance

Preciso recriar todas as páginas de um site e transformar ele em algo mais moderno gosto muito do conceito de efeitos de brilho fundo escuro efeitos de slide e animações de movimento com cada página abrindo um item tecnológico de cada cena, gostaria de fazer todo o sistema do site com a mesma estrutura semântica das pastas dos menus como o URL amigáveis mantendo a mesma página e caminho, peço que analise toda semântica e estratégia SEO, com todas as metas estruturas de títulos palavras-chaves de cada página. Meu site é bonito mas eu gostaria que você me desse uma ideia mais atraente mas marketing nas apresentações dos textos repare bem que eu sempre deixo em negrito e posiciono links estratégicos na estrutura. 

Site a ser refeito www.ncbrasil.com.br

Utilize um conceito de design profissional voltado para o marketing para montar a nova identidade visual mantendo as cores azul preto e branco.
